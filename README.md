# Открытая RL среда для поисковых агентов

Делаем open-source среду для обучения поисковых агентов. В статье описываем среду, обучаем в ней своего агента и показываем изменение метрики на отложенных задачах.

Постановка Сергея от 2026-10-30. Сейчас подготовлен проект документации; реализация среды и экспериментальные результаты — следующие этапы. Конкретные интерфейсы и метрика ниже пока предложены для первого примера.

## Результаты проекта

- Среда с задачами, корпусом, поисковыми инструментами и проверяемой наградой.
- Пример подключения и RL-обучения поискового агента.
- Кривые обучения и сравнение одной модели до и после обучения.
- Открытый код, конфиги и команды воспроизведения.

## Предыдущие наработки

Контекст команды и инфраструктуры — в [прошлом проекте](../os_jev_ru/PLAN.md). Текущую цель определяет постановка выше; старые сроки и экспериментальные схемы автоматически не переносятся.

Переиспользуем подходящие инфраструктурные компоненты: `tdfmt/tracking.py` для MLflow, подход к парным сравнениям по вопросам, сохранение и возобновление обучения, [скрипты GCP](../os_jev_ru/experiments/gcp) и [инструкцию запуска](../os_jev_ru/format/TRAINING.md). ## Начальная модель

Сергей выбрал Qwen3.5 и планирует завести аккаунт OpenRouter для первых прогонов агента. В сообщении размер указан как 8B; проверенная близкая официальная модель — [Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B), доступная как [`qwen/qwen3.5-9b`](https://openrouter.ai/qwen/qwen3.5-9b). Точный model id фиксируется перед первым запуском, без молчаливой замены линейки.

OpenRouter используется для разработки харнесса и исходной оценки. Пример RL-обучения подключается к весам модели в тренировочном окружении. Код вызова API — небольшая часть харнесса, которую ведёт Сергей.

По снимку от 2026-10-27 в GCP настроены проект `os-jev-ru`, бакет `gs://os-jev-ru-data` и Batch на spot G4. Проверен запуск обучения 2B с сохранением и возобновлением. Текущие квоты, доступность и остаток кредитов проверяются перед запуском.

В прежнем плане фигурировали 300 GPU-часов и API $200 в месяц, в GCP — кредиты $300. Это разные величины и не подтверждение текущего бюджета. Платные задачи требуют явного разрешения Сергея на конкретный запуск и лимит. Долгие вычисления и загрузку весов на Mac не начинаем.

## Ближайший шаг

Небольшой прототип без моделей: корпус, поиск, цикл эпизода, оценщик и журнал. После проверки подключаем одну модель, измеряем исходную метрику и добавляем тренировочный цикл.
