# Черновик задач для GitHub Issues

Актуализация от **2026-11-01** на три спринта: 02–08.11, 09–15.11 и 16–22.11. Дорожная карта — в [ROADMAP.md](ROADMAP.md), данные и методы — в [EXPERIMENTS.md](EXPERIMENTS.md). Issue ещё не созданы; ID ниже — локальные обозначения. Сроки — предлагаемые контрольные точки, индивидуальная загрузка не определена.

**Scope:** Text-to-SQL + RAG; оценка SQL-only, RAG-only и hybrid; обязательные GEPA, SFT и RL. После передачи харнесса **Коля + Дима ведут baseline и скорость, Сергей + Вова — данные GEPA/SFT**. У тикета один ответственный; помощники указаны в критериях. Пять вариантов сравнения и окончательный состав новых бенчмарков фиксируются до основных запусков.
