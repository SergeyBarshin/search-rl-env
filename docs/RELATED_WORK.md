## Обучение поисковых агентов

| Работа | Что предоставляет | Что сопоставлять с нашей средой |
|---|---|---|
| [Search-R1](https://arxiv.org/abs/2503.09516v5) и [код](https://github.com/PeterGriffinJin/Search-R1) | RL для чередования рассуждений и поисковых действий; маскирование текста результатов поиска при обучении | Контракт инструментов, тренировочный цикл, награду, данные и воспроизведение обучения |
| [T-Search](https://arxiv.org/abs/2610.06782) и [харнесс](https://github.com/turbo-llm/t-search-harness) | Поиск по фиксированному корпусу, ранжированные свидетельства, SFT и GSPO с recall-наградой, RU/EN-оценку | Устройство среды, инструменты, подключение других моделей и пример обучения |
| [GEPA](https://github.com/gepa-ai/gepa) | Оптимизацию текстовых параметров с обратной связью по траекториям | Отдельный эффект оптимизации промпта, стоимость поиска кандидатов и разделение train/dev/test |

README T-Search предупреждает о зависимости модели от исходных промптов, схем инструментов и ограничений. Для нашего сравнения до и после обучения используется один собственный контракт среды. Опубликованные числа из другого харнесса не являются непосредственно сопоставимой строкой нашей таблицы.

## Наборы для оценки

[BrowseComp-Plus](https://huggingface.co/datasets/Tevatron/browsecomp-plus) содержит 830 вопросов и корпус из 100 195 документов. Различаются evidence documents и gold documents, содержащие финальный ответ. Для награды фиксируем конкретный набор релевантности.

Retrieval-метрики BrowseComp-Plus проверяются по qrels. Официальная accuracy свободного ответа использует LLM-судью; детерминированный exact match не эквивалентен этой accuracy. [Описание оценщика](https://github.com/texttron/BrowseComp-Plus/blob/main/docs/llm_as_judge.md).

[TRuST](https://huggingface.co/datasets/t-tech/TRuST) содержит 324 русских вопроса, [SynthComp](https://huggingface.co/datasets/t-tech/SynthComp) — по 395 в RU и EN. TRuST использует оценку уровня документов. Preview имеет техническое имя split `train`, но карточки запрещают обучение на preview и публикацию расшифрованной версии. В нашем проекте вопросы этих наборов используются только для внешней оценки.

## Позиционирование статьи

Поисковое RL и открытые харнессы уже существуют. Раздел вклада должен конкретно описать возможности нашей среды: задачи, проверку награды, подключение агентов, данные и воспроизводимость тренировочного примера. Это пункты для сравнения, пока не доказанные преимущества над существующими системами.

Основное экспериментальное утверждение формулируется по результату: обучение конкретного агента в нашей среде изменило метрику на отложенных задачах на измеренную величину при указанных ресурсах. Для этого утверждения нужен чистый эксперимент до/после. Абсолютное лидерство на внешнем бенчмарке не требуется.
